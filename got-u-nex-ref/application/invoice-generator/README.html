RTBO Invoice Generator

Dashboard access

Open index.html, select Forms, then select RTBO Invoice Generator.

Data behavior

No clients, services, invoices, amounts, contacts, addresses, or payment records are preloaded. Existing dashboard profile and school records synchronize into the invoice workspace when those records exist. Standalone invoice records are stored in the browser.

Included functions

Create, edit, calculate, save, print, download, organize, report on, and manage invoice records, clients, services, recurring settings, payments, drafts, trash, activity, and the local Vault / Safe.

Production backend

Supabase authentication, permanent database and file storage, automated delivery, payment processing, live exchange rates, tax services, reminders, and webhooks require production credentials and backend integration.
