RAISING THE BAR OFFICIATING INVOICE GENERATOR
Dashboard Forms-Section Integration

ACCESS
1. Open the Got U Nex Ref dashboard index.html.
2. Select Forms.
3. Select RTBO Invoice Generator.

DATA
- No clients, services, invoices, amounts, contacts, addresses, or payment records are preloaded.
- The invoice generator starts with a new blank invoice using the current date and an automatically generated annual invoice number.
- Existing dashboard profile and school records are synchronized into the invoice workspace when those records exist.
- Invoice, client, service, activity, recurring, vault, and trash records are stored in the browser for this standalone build.

FUNCTIONS
- Create and edit invoices
- Add unlimited line items
- Calculate subtotals, discounts, taxes, fees, deposits, prior payments, and balances
- Manage actual clients and services
- Save invoice records to the local Vault / Safe
- Generate and download PDF invoices
- Print preview for US Letter and A4
- Prepare email, text, and device-share actions
- Manage recurring invoice settings, drafts, payments, reports, trash, and activity history
- Use desktop, tablet, and mobile layouts

PRODUCTION BACKEND
Supabase authentication, database records, permanent file storage, organization permissions, activity auditing, automated delivery, payment processors, live exchange rates, tax services, reminders, and webhooks require production credentials and backend integration.
