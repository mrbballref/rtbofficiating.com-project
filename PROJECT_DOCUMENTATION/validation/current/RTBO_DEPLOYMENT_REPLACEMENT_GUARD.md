# RTBO PUBLIC-SITE REPLACEMENT GUARD — CURRENT

The current public `rtbofficiating.com` design remains in place throughout project construction and validation.

Replacement is prohibited until all of the following are true:

1. all 11 standalone HTML/CSS/JS platforms are LOCKED;
2. the integrated HTML/CSS/JS enterprise is LOCKED;
3. the full-stack architecture and exact versions are frozen;
4. all full-stack platform/modules are LOCKED;
5. the integrated full-stack enterprise is LOCKED;
6. final cross-platform regression passes;
7. accessibility/security/performance/data-integrity/deployment-readiness gates pass;
8. a tested backup/migration/rollback plan exists;
9. the user explicitly approves deploying the exact locked release.

Deployment must preserve a recoverable copy of the current production site until the replacement is verified in production. Destructive removal without rollback is prohibited.
