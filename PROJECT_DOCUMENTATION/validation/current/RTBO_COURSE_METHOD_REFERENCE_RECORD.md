# RTBO COURSE METHOD REFERENCE RECORD — CURRENT

**Purpose:** document the external instructional patterns adopted for the post-lock RTBO curriculum. This record affects teaching structure only; it never overrides canonical project source or RTBO requirements.

## Coursera patterns adopted

Current Coursera web-development offerings use structured modules with combinations of videos, readings, programming assignments, hands-on labs, quizzes/assessments and final projects. Some courses progressively build a complete application across modules and explicitly include semantic HTML, responsive CSS, DOM/event work, accessibility and secure-data concepts.

RTBO adoption:
- clear modules and learning objectives;
- concept lessons before implementation;
- hands-on labs;
- programming assignments/practice tasks;
- knowledge checks/graded-style module assessments;
- progressive project milestones;
- final capstone projects.

## Udemy patterns adopted

Current major Udemy web-development bootcamps emphasize guided lectures, coding exercises, code-alongs, hands-on practice and multiple real-world portfolio projects, progressing from foundational browser/web concepts through HTML/CSS/JavaScript and full-stack development.

RTBO adoption:
- guided code-alongs using the exact locked RTBO source;
- coding exercises separate from canonical production source;
- real project milestones;
- debugging/get-unstuck practice;
- practical browser/DevTools verification.

## Zero To Mastery patterns adopted

Current Zero To Mastery web-development courses emphasize step-by-step progression from beginner concepts to modern full-stack systems, frequent real-world projects, hands-on exercises, best practices, performance/clean-code concerns, authentication/security, databases, deployment and production-oriented capstones. ZTM also publishes dedicated testing curriculum spanning unit, integration, API/back-end and end-to-end testing.

RTBO adoption:
- beginner-to-production roadmap;
- learning by doing;
- repeated real-world mini-projects and platform capstones;
- clean/performance-aware code;
- debugging/testing as first-class skills;
- frontend/server/database integration lessons;
- production/deployment and security concepts;
- unit/integration/API/E2E testing instruction where applicable.

## RTBO-specific additions that remain mandatory

The external course patterns do not replace RTBO rules. The RTBO curriculum additionally requires:
- exact repository/file paths;
- additive instructions unless correcting existing user code;
- complete validated logical blocks, not one-line-at-a-time default teaching;
- current source commit/hash/line-ledger proof with every production lesson;
- MDN/WHATWG/W3C/WCAG validation and W3Schools supplemental beginner reference;
- current official stack/provider documentation for full-stack material;
- no guessed routes/assets/configuration;
- cumulative project checkpoints;
- full project build/validation/lock before teaching begins.
