# RTBO Validated Code Governance

This directory is the canonical governance location for project-wide code validation across the Raising The Bar Officiating ecosystem.

No code may be taught, reused, integrated, or represented as approved unless it has passed the mandatory validation gates defined in `RTBO_MASTER_VALIDATED_CODE_RULE.md` and is recorded in the Validated Code Registry.

Validation covers:

- standalone HTML/CSS/JS implementations;
- integrated HTML/CSS/JS enterprise implementation;
- standalone full-stack implementations;
- integrated full-stack enterprise implementation;
- shared browser/core libraries;
- Master CMS + Super Admin;
- cross-platform routes, contracts, security, accessibility, metadata, PWA/offline, privacy, testing, observability, and deployment concerns.

The repository, current cumulative checkpoint, locked architecture documents, corrected route inventories, approved assets/content, and verified external standards are authoritative inputs. Conversational memory is never a substitute for source inspection.
