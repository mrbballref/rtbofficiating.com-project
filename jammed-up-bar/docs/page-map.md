## Global Navigation Link Map

The approved RTBO-style navigation is linked on every platform HTML page (excluding the embedded iPad player). The centered approved Jammed Up Bar! logo occupies its own grid column so navigation items do not overlap it.

- **Home** → `/index.html`
- **Live** → `/live/`
- **Watch** → `/watch/`
- **Listen** → `/listen/`
- **Shows** dropdown → Shows, Episodes, Podcasts, Films, Clips, The Jammed Up Play
- **News** dropdown → News, Topics, Sports, Guests, Hosts, Contributors, Expert Network
- **Explore** dropdown → Events, Newsletters, Archive, Awards, TV, Apps, Community, Submit A Jammed Up Play, About, Network, Studios, Digital, Publishing, Education, Business, Creative, RTBO Integrations, Shop, Advertise, Sponsorships, Media Kit, Licensing, Syndication, Production Services, Partner Portal, Press, Careers, Contact, Platform Status, Sitemap, Accessibility, Privacy, Terms, Copyright, Submission Terms
- **My Bar** dropdown → Account, Profile, Favorites, Watch Later, Listen Later, Continue Watching, Continue Listening, Playlists, Notifications, Admin Command Center
- **Search** → `/search/`
- **Subscribe** → `/subscribe/`

Individual show, episode, article, guest, film and event template routes remain content-detail destinations reached from published CMS records rather than being exposed as generic primary-navigation links. Admin sub-pages remain linked through the Admin Command Center's internal module navigation.
