PLATFORM GUIDE

The Cutting Room

Complete standalone HTML/CSS/JavaScript film review platform based on the supplied cinematic Cutting Room page.

Start Here

  1. Open index.html.
  2. Choose Upload Film and add an actual video file.
  3. Open the film in Review Studio.
  4. Add markers, comments, clip ranges, and evaluations.
  5. Create portable review packets or download records.

What Is Functional

  • Clip and full-game video upload
  • IndexedDB video storage
  • Film search/filter/download/delete
  • HTML5 video playback and frame stepping
  • Timecoded review markers
  • IN/OUT clip EDL ranges
  • Review comments
  • Film-based evaluations
  • Portable review packets
  • Browser Web Share fallback to download
  • Metadata backup/restore
  • Storage estimates and activity logs

Local-Only Limitations

A pure HTML/CSS/JS package cannot provide server-side multi-user synchronization, cloud video transcoding, persistent organization accounts, email delivery, or server-rendered trimmed video exports without a backend. This build keeps those interactions local and uses portable JSON packets for collaboration.

Recommended Use

For the most consistent browser storage behavior, serve this folder from a local/static web server instead of opening it directly from the filesystem. The package itself requires no npm install or build process.

python3 -m http.server 8080
