RTBO SUPER ADMIN ALL-ACCESS UPDATE

Copy this package over the matching Raising_The_Bar_Officiating_Complete_Platform folder.

Super Admin entry points automatically enable persistent All-Access Mode for the current browser origin.
Open: cms/access-center.html

All-Access Mode gives the Super Administrator administrative review access across pages, features, RefZone University pathways, and membership experiences without repeatedly signing in, creating a member account, enrolling, or paying.

The mode is persistent in browser localStorage until disabled from the All-Access Center. No fake user account or fake membership enrollment is created.
